# HainanZhao Tap

## How do I install these formulae?

`brew install hainanzhao/tap/<formula>`

Or `brew tap hainanzhao/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "hainanzhao/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
